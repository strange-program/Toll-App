Use Case 1: Interactive Web App

- Περιοδικός έλεγχος για νέα δεδομένα και recompilation των διαφόρων στατιστικών, διαγραμμάτων κλπ [μη λειτουργική απαίτηση] (1)

- Φόρτωση χάρτη ελλάδας με τα εμπλεκόμενα διόδια (1)
  
- Δυνατότητα εξαγωγής ενός csv/json με όλες τις πληροφορίες για εκμετάλλευση από την κάθε οδό (1)

- Μενού με διάφορα στατιστικά και διαγράμματα (π.χ. Dependency wheel, Διάγραμμα επικύρωσης κάρτας ανά διόδιο, ανά οδό, ανά πάροχο, ανά χρονικό διάστημα κλπ) (1)
    
- On click σε διόδιο βγαίνει αναδυόμενο popup με πληροφορίες (όνομα, οδός, επικυρώσεις κάρτας κλπ) (3)

- login με users (guest με ενδιαφέρουσες πληροφορίες μόνο, admin για κάθε οδό ξεχωριστά με ευαίσθητες για την εταιρία πληροφορίες) για διαχωρισμό πληροφοριών / views (αν έχει κάνει login ως user με χαμηλά/υψηλά δικαιώματα, ως user κάποιας συγκεκριμένης εταιρίας που έχει πρόσβαση στα δεδομένα που αφορούν αυτή ή αν έχει κάνει login ως guest) (2)

- Εμφάνιση login screen με πεδία username και password και κουμπί login as a guest (1)
  
- Dashboard/Sidebar για πλοήγηση στις διάφορες δυνατότητες της εφαρμογής (2)

- On click σε διόδιο βγαίνει αναδυόμενο popup με πληροφορίες (όνομα, οδός, επικυρώσεις κάρτας κλπ) (3)

Οι απαιτήσεις αυτές είναι πολλές και ενδεχομένως να μην μπορούμε να τις υλοποιήσουμε όλες. Προς αυτό σημειώνεται δίπλα η προτεραιότητα της κάθε απαίτησης.
1. Αναγκαστικό 
2. Σημαντικό 
3. Χρήσιμο 
4. Συμπληρωματικό
