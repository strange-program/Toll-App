Use Case 1: Interactive Web App

- Περιοδικός έλεγχος για νέα δεδομένα και recompilation των διαφόρων στατιστικών, διαγραμμάτων κλπ [μη λειτουργική απαίτηση] 

- Φόρτωση χάρτη ελλάδας με τα εμπλεκόμενα διόδια 
  
- Δυνατότητα εξαγωγής ενός csv/json με όλες τις πληροφορίες για εκμετάλλευση από την κάθε οδό 

- Μενού με διάφορα στατιστικά και διαγράμματα (π.χ. Dependency wheel, Διάγραμμα επικύρωσης κάρτας ανά διόδιο, ανά οδό, ανά πάροχο, ανά χρονικό διάστημα κλπ) 
    
- On click σε διόδιο βγαίνει αναδυόμενο popup με πληροφορίες (όνομα, οδός, επικυρώσεις κάρτας κλπ) 

- login με users (guest με ενδιαφέρουσες πληροφορίες μόνο, admin για κάθε οδό ξεχωριστά με ευαίσθητες για την εταιρία πληροφορίες) για διαχωρισμό πληροφοριών / views (αν έχει κάνει login ως user με χαμηλά/υψηλά δικαιώματα, ως user κάποιας συγκεκριμένης εταιρίας που έχει πρόσβαση στα δεδομένα που αφορούν αυτή ή αν έχει κάνει login ως guest) και εμφάνιση login screen με πεδία username και password και κουμπί login as a guest
